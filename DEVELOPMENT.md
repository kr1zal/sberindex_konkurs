# Устройство проекта

Прогнозирование потребительских расходов муниципальных образований и обнаружение
точек структурных изменений. Подробности задачи — в `README.md`.

## Структура

```
configs/baseline.yaml   протокол оценки: данные, разбиение, выборка, модели, параллелизм
src/data.py             загрузка панели, восстановление сущностей МО, обработка пропусков
src/regions.py          привязка к регионам и ОКТМО по справочнику СберИндекса
src/split.py            скользящий origin с расширяющимся окном
src/metrics.py          MAE, R², sMAPE, MASE
src/external.py         длинные ряды СберИндекса и перенос с них общего фактора
src/models/             модели прогноза за единым интерфейсом fit/predict
src/changepoints.py     детекторы точек структурных изменений
src/run.py              прогон и сводка
scripts/fetch_sberindex.py  выгрузка длинных рядов из каталога СберИндекса
scripts/check_no_leakage.py проверка, что модели не читают данные после origin
data/raw/               панель СберИндекса (parquet)
data/reference/         справочник МО, ключевая ставка
data/reference/sberindex/  длинные федеральные и отраслевые ряды
results/                выход прогонов, в git не попадает
```

## Правила

- **Протокол оценки живёт только в `configs/baseline.yaml`.** Ни горизонта, ни правил
  разбиения в коде моделей — иначе сравнение перестаёт быть сравнением.
- **Новая модель** реализует `fit(y) -> self` и `predict(horizon) -> np.ndarray`
  и регистрируется в `src/run.py::REGISTRY`. Больше ничего менять не нужно.
- **Панельная модель** живёт в `GLOBAL_MODELS`, работает с матрицей целиком
  (`fit(wide, train_end, horizon)`) и получает внешние данные через `PanelContext`.
- **Длинные ряды идут дальше панели** — федеральные до августа 2026, панель
  до декабря 2024. Любое обращение к ним обрезается по origin. Проверяется
  скриптом `scripts/check_no_leakage.py`, запускать после правок в `src/external.py`.
- **Ничего не выбрасывать молча.** Любое исключение ряда попадает в отчёт прогона.
- **Не подгонять базовую модель под себя.** Если конфигурация эталона меняется,
  обе версии считаются как отдельные модели и показываются обе.
- **Регион не приписывается омонимичному названию.** «Не определено» лучше, чем неверно.
- Комментарии объясняют **почему**, а не что.

## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -u src/run.py --config configs/baseline.yaml
```

Тяжёлые прогоны запускать в фоне и не пропускать вывод через `grep` или `tail` —
они буферизуют, и лог остаётся пустым до самого конца.

Перед первым прогоном моделей с длинными рядами:

```bash
.venv/bin/python -u scripts/fetch_sberindex.py
.venv/bin/python -u scripts/check_no_leakage.py
```
